# 本底估计与本底注入（bkg_est_add）

本目录实现任务要求的 5 个步骤：不直接模拟实验室本底，而是用「剂量率 + 假定沉积能谱 + 棱台晶体体积 + 泊松统计」的保守数值方法，估计每个事例中 gamma 本底的期望个数 `n_bkg`，并把本底能量沉积注入 `data/processed/` 的预处理数据。

| 内端面平均面积（R = 260 mm） | `S₁` | **1319.380 mm²** |
| 外端面平均面积（R = 540 mm） | `S₂` | **5691.289 mm²** |

| 实际晶体数（探测器上下游各一个缺口） | `N` | **568** |

## 方法

### 第 1 步：GP(8,0) 哥德堡多面体与晶体体积

第一类（class-I，即 `(m,n)=(8,0)` 无手性歧义）GP(8,0) 是频率 8 的 class-I 测地线球（icosahedron 每个面按重心坐标剖分为 8²=64 个小三角形、再投影到球面）的**对偶**多面体：

- 12 个 icosahedron 顶点 → 12 个五边形；其余 630 个顶点 → 630 个六边形；
- 642 个面、1280 个顶点、1920 条棱，Euler 特征数 1280 − 1920 + 642 = 2（已断言检查）；
- 面元面积用 Newell 公式（对轻微非共面的多边形取向量面积）计算。

内半径 260 mm 时，面面积总和 847 041.7 mm²，比同半径球面 849 486.7 mm² 小 0.29%（平面面元的正常效应）。外表面由同一多面体做均匀径向放大得到，因此

```
S₂ = S₁ · (540/260)²   （代码同时用 R = 540 mm 重建多面体并逐面验证，相对差 < 1e-12）
```

晶体体积采用**精确棱台公式**（两端面平行、面积分别为 S₁、S₂，高 L）：

```
V_cry = L/3 · (S₁ + S₂ + √(S₁·S₂))
      = 280/3 × (1319.380 + 5691.289 + 2740.250)
      = 910 085.7 mm³ = 910.086 cm³
```

> 参考：梯形近似 `(S₁+S₂)/2·L` 会给出 981 494 mm³，比精确值高 7.8%，本实现已改用精确公式。

### 第 2 步：平均能量沉积

假定本底 gamma 在单块 CsI 晶体中的沉积能谱为正态分布 `N(μ=5 MeV, σ²=2 MeV²)`。由于负沉积能无物理意义，实际使用**截断于 E>0 并重新归一化**的正态分布（截断对均值的影响仅 0.02%）：

```
E_bkg = ∫₀^∞ E · f_trunc(E) dE = 5.001089 MeV ≈ 5 MeV
```

### 第 3 步：剂量率 → 本底事例率

任务给定的「能量沉积功率」`P_bkg = 30 μSv/h` 是环境剂量当量率。对光子取辐射权重因子 1，并按 `1 Sv = 1 Gy`、`1 Gy = 1 J/kg` 换算：

```
D = 30×10⁻⁶ Gy/h / 3600 s/h = 8.3333×10⁻⁹ Gy/s = 8.3333×10⁻⁹ W/kg
M_total = N · m = 568 × 4.1045 = 2331.3 kg
P_total = D · M_total = 8.3333×10⁻⁹ × 2331.3 = 1.9428×10⁻⁵ W
r_bkg = P_total / E_bkg = 1.9428×10⁻⁵ / (5.001089 × 1.602176634×10⁻¹³ J/MeV)
      = 2.4247×10⁷ s⁻¹
```

计算事例率使用的体积是**所有晶体的体积之和**：理想 GP(8,0) 有 642 个面，但实际探测器在上游和下游各有一个缺口，只有 568 块晶体，因此 `V_total = 568 × V_cry`（这一数字由 GDML 几何和 `Edeps` 长度 568 共同确认）。

### 第 4 步：时间窗 → 每事例本底个数

```
n_bkg = r_bkg · Δt = 2.4247×10⁷ s⁻¹ × 100×10⁻⁹ s = 2.4247
```

### 第 5 步：注入本底

对每个事例 `i`：

1. 抽 `k ~ Poisson(n_bkg)`（平均约 2.4 个 hit）；
2. 在数据实际存在的 568 个晶体编号中**均匀、有放回**地抽 `k` 个编号（若撞到同一晶体则能量相加，物理上对应同一晶体的多次击中）；
3. 从第 2 步的截断正态能谱抽 `k` 个能量；
4. `Edeps[mod] += E`。

输出文件保持 `EdepOfEachEvt/Edeps` 的原有 schema（可直接作为 `reconstruction.py` 的输入），并新增 `NBkg` 分支记录该事例注入的本底 hit 数；文件内另有名为 `bkg_model` 的 `TNamed` 元数据（JSON），保存全部参数、随机种子与模型结果。随机数按 `numpy.random.default_rng([seed, crc32(dataset)])` 生成，种子默认 `20261105`，因此结果完全可复现。

```bash
cd pytrial/bkg_est_add
python add_background.py                 # 默认：三个数据集、全部 1e6 事例
python add_background.py --datasets mu_rest --max-events 10000   # 快速测试
python verify_background.py              # 逐事例回读校验
```

## 校验（`bkg_verification.json`）

`verify_background.py` 用输出文件里保存的种子**重新生成**全部随机数，再逐事例比较原始文件与注入文件：

- `NBkg == 0` 的事例必须与原始文件逐位相同；
- `NBkg > 0` 的事例的差值必须与重新生成的沉积能完全一致（实测最大偏差 **0.000 MeV**）；
- `NBkg` 分布与 `Poisson(n_bkg)` 的一致性（χ² 检验，0–6 及 ≥7 分箱）；
- 晶体编号使用频率的均匀性（χ² 检验）；
- 平均每 hit 能量与 `E_bkg` 的一致性。

| 数据集 | 注入 hit | 含本底事例 | Poisson p | 均匀性 p | 平均能量 (MeV) | 结论 |
|:---|---:|---:|---:|---:|---:|:---:|
| `ep_iso` | 2,424,355 | 911,326 (91.13%) | 0.906 | 0.817 | 4.9998 ± 0.0009 | PASS |
| `gamma_iso` | 2,424,215 | 911,421 (91.14%) | 0.596 | 0.535 | 5.0000 ± 0.0009 | PASS |
| `mu_rest` | 2,424,505 | 910,960 (91.10%) | 0.362 | 0.598 | 5.0002 ± 0.0009 | PASS |

另外，用现有 `reconstruction.py`（`Eth_seed=5`、`Eth_wave=1`、`Nth=2`）在 `mu_rest_bkg` 的 3000 事例子集上跑通了完整的「聚类 + 打分」流程，确认输出文件与现有 pipeline 的接口兼容。

## 几何交叉检验（`check_geometry_gdml.py`）

`data/raw/*.root` 中内嵌了探测器的真实 GDML。逐块解析 568 个 `ECALCrystal_*` 的 tessellated solid，得到实测的端面面积与体积：

| 量 | GDML 实测平均 | GP(8,0) 模型 | 比值 |
|:---|---:|---:|---:|
| 内端面面积 | 1294.08 mm² | 1319.38 mm² | 0.981 |
| 外端面面积 | 5582.14 mm² | 5691.29 mm² | 0.981 |
| 单晶体积 | 885 850.6 mm³ | 910 085.7 mm³ | 0.973 |

结论：GP(8,0) 对晶体端面尺寸的描述与真实几何相差约 2%，对单晶体积相差 2.7%，说明该多面体近似是可靠的。剩余差异来自：

1. 实际晶体被相邻晶体之间的分割面切成截头棱台（prismatoid），其中 12 块位于 icosahedron 顶点的角部晶体只有 429 276 mm³（约为典型晶体 960 524 mm³ 的 45%）。这与 GP(8,0) 中 12 个五边形面仅为六边形面积一半的特征一致；模型用统一平均截面计算，因此平均体积偏高。
2. 梯形公式 `(S₁+S₂)/2·L` 会给出 981 494 mm³（比精确棱台公式高 7.8%），本实现已按精确公式计算。

## 重要假设与口径说明

1. **剂量换算**：取 `1 Sv = 1 Gy`（光子 w_R = 1），并把 30 μSv/h 的环境剂量率直接当作 CsI 中的吸收剂量率。实际上 CsI 与空气的质能吸收系数之比强烈依赖光子能量（低能段 CsI 明显更高，1 MeV 附近反而略低），因此该近似会带来 O(1) 量级的系统不确定度，方向取决于本底能谱。这是本估计最主要的系统不确定度之一。
2. **能谱**：均值 5 MeV、方差 2 MeV² 的正态分布，截断于 0。`r_bkg ∝ 1/E_bkg`，若真实平均沉积能不同，结果按反比缩放。
3. **晶体数 642 vs 568**：GP(8,0) 有 642 个面，但探测器上下游各有一个缺口，实际只有 568 块晶体（`ModID` 0–567）。体积估计使用完整多面体的平均面面积；注入时只在数据实际存在的 568 个通道中随机取编号。
4. **体积口径**：事例率使用**全部 568 块晶体的体积之和** `V_total = 568 × V_cry`，因此 `n_bkg = 2.4247` 是整个探测器在 100 ns 内的期望本底 hit 数；第 5 步按此数逐事例抽样并把每个 hit 随机分给一块晶体。作为参考，单块晶体对应的期望值为 `n_bkg / 568 = 4.27×10⁻³`。
5. **事例窗**：100 ns 为任务给定值；`n_bkg ∝ Δt`。
6. **单位**：`Edeps` 的能量单位为 MeV（与 Geant4 输出一致）。

## 复现方式

```bash
cd pytrial/bkg_est_add

# 第 1–4 步：打印计算过程、写 bkg_estimation.json 和能谱图
../../.venv/bin/python estimate_background.py --plot bkg_spectrum.png

# 几何交叉检验（可选）
../../.venv/bin/python check_geometry_gdml.py

# 第 5 步：注入（约 65 s / 3 个文件）
../../.venv/bin/python add_background.py

# 校验（约 2 min）
../../.venv/bin/python verify_background.py --json bkg_verification.json
```

> 依赖：CERN ROOT 的 PyROOT（已在 `PYTHONPATH` 中）、numpy、scipy、matplotlib。
> `data/processed/*.root` 受 `.gitattributes` 的 Git LFS 规则管理；新增的 `*_bkg.root` 为派生数据，可随时用上面的命令重新生成。
