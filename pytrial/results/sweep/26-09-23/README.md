## 结论

1. **算法已到达接受度上限。** 全局最佳点是 `Nth=0, seed=12, wave=0.5` 的 `ep_iso`：
   **exact = 0.8786**。而接受度地板（ECAL 总沉积 < 1 MeV 的事例约 12%）给出的理论上限
   约 0.88 —— **即所有有能量的事例都恰好给出 1 个团簇**。

2. **`Nth` 是主导参数，且越小越好。**
   | `Nth` | 最佳 mean exact |
   |--:|--:|
   | 0 | **0.866** |
   | 1 | 0.849 |
   | 2 | 0.762 |
   | 3 | 0.533 |

   把邻居数要求放在**种子**条件上是代价高昂的：`Nth=3` 相对 `Nth=0` 损失约 0.33。
   几何上原因很清楚 —— 一个单粒子簇射只有 4–6 块晶体（其总能量中位数 53 MeV，
   而晶距 46 mm 已接近簇射横向尺度），要求种子有 3 个"点亮"邻居会直接抹掉大量事例。

3. **`Nth = 0` 时 `Eth_wave` 几乎不起作用**（整行 0.775–0.866 只随 seed 变化）。
   因为种子判据不再引用它，波前阈值只剩"生长/吸收"作用，而只要波前一开始传播，
   它就会把连通区里所有点亮晶体吸进来 —— 结果是 1 个簇或 0 个簇。

4. **`Nth ≥ 1` 时 `Eth_wave` 变得关键**：必须压到 0.5–1 MeV
   （`Nth=1`：wave 0.5 → 3 MeV 时从 0.849 掉到 0.606）。


6. **仍有未测量的一环**：以上都是单粒子样本，`exact_match` 衡量的是"簇数等于 1"。
   要验证**分辨多粒子的能力**，需要多粒子事例样本（此前用过的
   `child_stitched_edeps.root` 因 `evt_stitch_child.py` 有缺陷已废弃），或者把三个
   单粒子数据集按已知重数叠加。这是下一步该补的评测。

## 推荐工作点

| 目标 | 建议 |

| 单粒子簇数最准 | `Nth=0, Eth_seed=7, Eth_wave=0.5`（mean 0.866）或 `seed=12`（ep_iso 0.879） |
